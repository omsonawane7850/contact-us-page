# Contact Us

A simple and responsive Contact Us form built with React.js.

## Features

* Name, Email, Subject, and Message fields
* Form validation
* Error messages
* Auto-focus on invalid fields
* Loading state on submission
* Success message
* Form reset after submission
* Responsive design

## Tech Stack

* React.js
* JavaScript
* Vite
* CSS Modules

## Run Locally

```bash
npm install
npm run dev
```

## Note

Form submission is currently simulated using `setTimeout()` and the submitted data is logged to the console.
